# VSYNC 分阶段行数测试

本版仅增加被动监测，不修改摄像头寄存器、采集窗口或接线。用于区分 HREF 行脉冲出现在 VSYNC 高电平还是低电平阶段。软件验证不等于实板问题已经修复。

1. 在 Vivado Hardware Manager 下载 `build/vivado/stream_top.bit`。不要误选 FPGA_demo 工程中旧的 bit。
2. SW0=0、SW15=0、SW14=1、SW12=0；其余开关先设 0。按一次 BTNC，等待至少 3 秒。
3. 按下表逐项切换，不必每次复位。每项记录 LED15→LED0 的完整 16 位（1=亮）。

| SW11/SW10 | SW13 | LED15..8 含义 |
|---|---|---|
| 01 | 0 | VSYNC 高阶段行数的低 8 位 |
| 01 | 1 | VSYNC 高阶段行数的高 8 位 |
| 10 | 0 | VSYNC 低阶段行数的低 8 位 |
| 10 | 1 | VSYNC 低阶段行数的高 8 位 |

LED15 始终是显示字的最高位。行数=高字节×256+低字节，例如低字节11110000、高字节00000000代表240行。LED7..0仍为状态，不参与行数计算。

计数来自 FPGA 同步后的 HREF 上升沿；在每个 VSYNC 阶段结束时锁存，饱和上限65535。首个阶段可能不完整，等待数帧后观察。高低字节分次读，如果读数变化，请说明范围或闪烁情况。

SW11/SW10=00 仍显示原来的 WR 捕获窗口行数；11 保留为零。SW12=1 时仍为原寄存器读回页。

若完整有效行集中在一个阶段，再对照原 WR 窗口判断；不能仅凭此读数证明 AL422B 已正确写入。尤其 WRST 当前接 VSYNC，不应在没有确认 FIFO 写复位关系时直接翻转采集极性。
