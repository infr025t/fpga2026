## 已执行

- 五套 RTL 仿真全部通过：FIFO 两帧读出/Y 字节位置/超时、SCCB 39 项配置与 NACK 释放总线、图像核、UART 传输、顶层连续两帧测试图。
- 图像核按真实 320×240 尺寸测试 12 帧，每帧 75684 个输出，独立卷积参考逐像素检查，包含模式/阈值锁存、灰度中心位置、不同输入间隔、坐标和、阈值等号、帧结束。
- Python 接收器 6 项测试通过，覆盖分片、坏 CRC、非法头部、截断后恢复、payload 内 magic、空质心及文件输出。
- 从真实 UART RTL 引脚波形解码生成 wire.bin，交给交付版 receiver.py，正确接收两帧并生成 PGM/JSON/CSV。
- 完成综合、布局布线、DRC 与 bitstream 生成。
- 100 MHz 时序：WNS **+3.087 ns**，TNS 0；WHS **+0.045 ns**，THS 0。报告结论：All user specified timing constraints are met。
- BRAM：24 个 RAMB36E1 + 3 个 RAMB18E1，折合 **25.5/50 个 BRAM Tile，51%**。三行缓存确实映射为三个 RAMB18，输出缓存占主要资源。
- LUT 706/20800（3.39%），寄存器 1041/41600（2.50%），DSP 0。DRC 无错误，保留一个 RPBF-3 警告：SIOC 声明为开漏 inout，但本设计不读回时钟、不支持 clock stretching，输入缓冲被优化。该警告未阻止 bitstream 生成，没有降低 DRC 严重级别。

## 尚未验证

没有下载到实板，没有读取实际摄像头，没有确认你的 22 针模组的供电、排针顺序、板载振荡器或内部 HREF/WEN/WRST 接法。接线必须按 README 的信号名和适配条件核对。寄存器组合与 FIFO 首字节、帧尾刷新行为仍需实物联调确认；行为仿真不等于芯片级模型。

静态时序使用 XDC 给定的外部延迟预算及多周期采样约束，不代表任意线缆和模组都已满足电气时序。异步开关、VSYNC、慢速 SCCB 输入具有文档说明的例外；外部不同时钟域的原始写入由模组 FIFO 承担。

该样例不实现端到端无帧缓存、UART 重传、FPGA 除法质心、多目标识别、1 bit 压缩或 15 fps 实测。它交付的是完整源码与可综合、已通过软件验证的硬件适配基准。
