# 工程整理约束

本轮依据用户要求收敛当前自主字符识别测试工程，生成最终报告所需的真实原始参考材料。基线为`historical/plate_autonomous_board_20261101/build_split`，不以视频旧正式仓库替代识别基线。

1. 自有源文件、脚本、文档名称全部小写下划线；生成文件、第三方工具产物与原始历史证据单独标识，不伪改历史。
2. RTL按`top`、`drivers/camera`、`drivers/display`、`drivers/uart`、`video`、`recognition`、`debug`、`common`划分。驱动不可依赖识别业务。模块按职责/接口划分，不把紧密耦合算法状态机机械拆成碎片。
3. 从顶层提取相机初始化控制、确定性测试图模块，保持周期语义。PC分离协议、传输采集、帧分组、参考验证、命令入口。所有调试模式、错误保护和暂停/复位行为继续保留。
4. 不改模型、CNN数学、归一化、定位/前缀/粘连阈值、相机读取参数、LCD总线时序。新增用户确认的三模式开关：SW4=1优先OCR；SW4=0时SW3=1为EDGE、SW3=0为RAW；原SW2边缘功能移到SW3，SW2保留。其余调试开关保留。不新增算法，不调质量参数。
5. 当前自有RTL源列表集中维护；构建冻结精确文件集合及哈希。仿真使用同一列表并独立测试顶层新模块的周期等价性。
6. 自有新增代码用中文简要注释解释职责、接口、修复缘由及边界，不把猜想写成根因。
7. 文档区分当前架构、接口与运行、算法原理、异常清单、数据与验证、资源时序、历史与证据索引。定量结论必须指向文件/哈希/阶段；参考一致率与识别正确率分开，视频速率与OCR速率分开。
8. 旧目录、历史采集/构建不可改写；COM15禁止访问；仅COM10。若下载仅写配置RAM，不写Flash，不推送Git。结构性重构必须通过仿真、布局布线及可用的实机验证后才称为当前有效版。
