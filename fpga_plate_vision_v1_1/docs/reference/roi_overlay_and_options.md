# 实际定位区域显示

绿色ROI框把识别前端实际选择的区域呈现在LCD画面中，让使用者直接判断目标是否完整进入识别范围。v1.0已实现此功能并获得用户显示确认，v1.1沿用该显示模块；自主OCR中切换SW5也会清除旧框，按下一显示帧边界更新。实现将坐标事件与显示渲染分开，既保留原识别数学，也使区域反馈能够独立检查。

## 坐标和显示规则

- OCR模式启用绿框；RAW、EDGE及人工/诊断接管时关闭自主区域显示。
- 框取自分割实际使用的`selected_x0/y0/x1/y1`。160×120坐标使用半开区间，乘4得到640×480坐标，边框宽2像素、RGB565颜色`07e0`。
- LCD水平居中偏移80由窗口驱动加入，ROI模块使用图像局部坐标，不重复加偏移。
- 新坐标先暂存，在下一显示帧边界统一提交，一帧内保持同一组坐标。显示表示最近完成的定位结果，运动场景下可能相对当前视频滞后。
- 未定位、区域越界或采集中止会使待显示框失效，并在下一显示帧边界清除；退出OCR清除旧框，重新进入等待新事件。
- 边框在显示队列出队后覆盖RGB565，保留原灰度输入、OCR原图、归一化像素及源CRC；暂停视频时画面与其边框一同保留。

绿色表示几何区域已选中；具体文字识别结果按真值另行评分。源码：[plate_roi_overlay.sv](../../project/rtl/video/plate_roi_overlay.sv)、[video_lcd_sink.sv](../../project/rtl/video/video_lcd_sink.sv)。

## 放置反馈与区域选择

定位器扫描整张160×120小图，依据亮底、近水平、带高12..60、宽至少64等规则选择区域。绿框使这些规则的实际输出可见，便于调整目标距离与位置，使整个牌面进入画面并保留边缘空间。

[数字平移试验](../../evidence/validation/roi_tolerance_probe/translation.json)将同一保存图按5组水平、5组垂直偏移组成25种情况，其中20种得到定位；向右8个小图像素的5种情况未定位。这组实验说明该图在既定规则下的位置响应，物理位置容差需另按真实摆放测量。当前前缀候选现象和评分统一见[验证数据](validation_data.md)。

## 后续类别扩展的接口成本

当前36类CNN与ASCII字库支持英数字。若扩展汉字类别，需要新增标注样本、训练与整数导出，调整固定36分数的控制器/协议及显示编码；前端仍需提供完整单字区域。仅扩最后全连接N类时，权重与偏置至少增加`768N+4N=772N`字节，另有字库、缓存与打包成本；超过64类还需扩大当前6位类别索引。v1.0基线BRAM36等效占89%，应先按真实存储映射预算。相应评估任务列于[扩展路线](limitations_and_next_steps.md)。
