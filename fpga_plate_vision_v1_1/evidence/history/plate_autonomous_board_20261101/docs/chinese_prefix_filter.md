# 首位汉字区域排除

## 规则与适用范围

本轮针对已发现的AG伪前缀：两个位于牌面最左侧、互相重叠的汉字碎片进入字符识别。自动模式按“首位为汉字、后面为字母数字”的版式，先定位整块牌面，再在字符候选进入同行筛选前排除以下区域：

`2*x + width < 2*(roi_x0 + floor((roi_x1-roi_x0)/8))`

即候选中心落在牌面最左1/8内则忽略，恰在边界则保留。边界随牌面平移、缩放；不使用CNN类别、答案或指定字符数量。不会盲目删除第一个分割框，也不会根据AG字样删除预测结果。

这是明确的版式约束，不是通用汉字分类器。对没有汉字前缀、或汉字不在最左侧的图片应关闭`SKIP_CHINESE`；当前顶层自主模式开启，人工回放模式始终关闭。尚未解决末尾4/5粘连、部分B/H混淆，亦未增加多帧投票。

## 实现

`char_segmenter`增加可选候选过滤，在任务开始时锁存开关和相对边界，在候选计数/同行筛选前执行。默认参数关闭以保留原单元行为。`plate_segment_frontend`在自动定位模式开启过滤，手动模式关闭；CNN、归一化、相机、动态定位和LCD模块保持不变，无新增帧缓存。

自动观测使用ASG3，布局与ASG2相同，284字节，表示启用此前缀过滤；观察器仍兼容ASG1/2，并按包版本独立计算预期框。因此旧ASG2记录不会被悄悄套用新规则。
