# 牌面位置容忍度测试记录

## 变化

原版要求牌面与固定小图ROI `(26,41,150,76)` 对齐。新版在完整160×120小图中寻找亮底牌面，每次采图后重新计算ROI，再调用原分割、归一化和CNN。没有按字符类别选择区域，没有指定必须6位或7位，没有新增多帧投票、置信度选择或训练。

适用范围为单块、近水平、亮底暗字、背景有亮度区分且完整留在镜头内的牌面；并非任意车牌检测器。几何参数和共享RAM调度见[设计合同](placement_tolerance_plan.md)。字框随牌面平移，牌面本身过大、截边、倾斜或模糊仍可能失败。

## 实现与观测

新增 `plate_region_locator.sv` 和 `plate_segment_frontend.sv`。定位、分割与归一化串行共享原有19,200B小图存储器；相机、视频、识别控制器、原分割器、归一化、CNN和字模模块未改。AUTO观测使用ASG2携带动态ROI；AIF1仍保存同帧完整小图，表示全图搜索范围。未找到牌面时ASG2的ROI全零、字符数为零，屏幕显示NONE，不沿用上一帧区域。

## 构建与实机状态

`build_locator/autonomous_board.bit` 已生成并下载配置RAM。WNS +0.097ns、WHS +0.012ns，TNS/THS均为0；15,018 LUT、18,638 FF、40 RAMB36+9 RAMB18、9 DSP。相较叠字版增加278 LUT、298 FF，没有增加BRAM或DSP。最终哈希见 `reports/locator_artifacts.json`。

下载后首轮10帧均与软件定位参考一致，均未找到牌面，采集/观测丢包计数为0。但当时镜头已换成深底白字、号码右侧超出画面的图像，与本轮亮底完整牌面合同不同；`--truth BD12345`沿用原号码，已标注该轮真值评分不适用，不能用其0/10作算法准确率统计。现场图与说明见 `reports/locator_board_precheck/current.png`、`context.json`。后续已完成一次完整入镜实拍，见下节；位置容忍度整链验收尚未通过。

仅在独立测试目录迭代，不更新Flash或正式仓库。识别按单帧直接更新，仍可能跳字；没有加入本轮明确排除的多帧稳定确认机制。

## 完整入镜后的失败实拍

`reports/placement_test_03` 连采10张：牌面完整入镜，动态ROI为(7,67,156,107)，硬件定位、框、61,440归一化像素和2,880分数均与参考一致。但3张为AGBD123K、7张为AGBD123M，BD12345整串正确为0/10。前两个重叠框来自汉字区域碎片，末框(124,76,32,31)合并4与5。证明该位置定位成功，但原分割器在扩大输入区域后仍有汉字干扰及背景粘连问题，不能宣布放置宽容度验收通过。现场图及诊断见该目录current.png、diagnosis.json。
