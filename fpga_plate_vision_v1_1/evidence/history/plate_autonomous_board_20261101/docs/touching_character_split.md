# 字符粘连分割优化（独立测试工程）

## 问题与修改边界

上一版已去掉汉字产生的AG前缀，但当前放置位置的BD12345仍输出BD123K或BD123M。检查同一张160×120原始灰度图和15×15局部阈值二值图后发现：4、5主体之间有空隙，牌面下沿的一行暗像素却把它们连成一个8连通域。原分割器把这个32×31的区域作为单字符交给CNN。

本次在连通域候选阶段加入受限的投影拆分；不改变摄像头读取、视频显示、归一化、模型权重或CNN计算。保留动态牌面定位与汉字前缀排除，不固定6位/7位，也不把BD12345写入预测规则。真值只在预测结束后评分。

## 整数规则

1. 先按原高度、面积及前缀策略筛选。仅宽度W满足H≤W≤2H的域尝试拆分。
2. 统计这个域自身的每列前景像素数P[x]，不统计边界框中别的连通域。
3. 切口s仅搜索W≤3s≤2W。最小化P[s−1]+P[s]，并列取靠左切口。这个两列总数必须≤floor(H/8)，否则不拆。
4. 根据切口两侧原域像素分别收紧包围框。两边宽度至少2、高度符合原限制且不低于原域3/4；宽度不超过原域高度4/5、面积不低于子域高度，并再次满足前缀区限制，才接纳两个子框。
5. 任一条件不满足则退回原单框规则。每个域最多拆一次，不递归拆成指定数量。两个子框一起检查64候选容量，不允许计数回绕或只提交半对。

这是一条针对细桥粘连的几何规则。浓墨粘连、三字连在一起、严重模糊、特别宽且有稀疏笔画的字体仍可能失败。M/W合成用例只能说明这些具体用例未误拆，不能证明所有字体都不会误拆。

## 硬件实现

洪泛队列中本来就保留该域全部像素坐标。洪泛结束后复用同一队列：第一遍累计160列、每列7位的墨量直方图；找到切口后第二遍计算两边边界与面积。无新增帧缓存、二值图副本或外部存储。直方图只清当前域的列范围，策略在任务开始时锁存。

`char_segmenter.ENABLE_SPLIT`默认关闭；自动模式由`SPLIT_TOUCHING`开启，人工回放继续执行原分割规则。当前顶层自动模式同时开启前缀过滤与拆分。

串口ASG4表示动态ROI、前缀过滤与拆分同时启用；ASG5表示动态ROI与拆分、无前缀过滤。二者维持284字节布局。ASG1/2/3旧记录仍按各自原算法核验，避免软件升级后错误解释历史数据。

- RTL单元：12组图像，含原策略关闭、实拍/平移/旋转/反相、薄桥/厚桥、宽M/W和空帧；另验证任务中策略变化、直方图期间复位与双候选容量边界。见`reports/split_rtl/green.log`。
- 原实拍完整自主链：7字符、5,376个归一化像素、252个有符号分数及ASCII全部匹配；随后空图无旧结果残留。13个串口包45,832字节逐项核验通过。见`sim_work/auto_split_scene/wire_verification.json`。

## 构建与实机验证

- 已生成并下载`build_split/autonomous_board.bit`到配置RAM，当前保持自主识别与屏幕输出。未写Flash，未修改正式仓库。
- 初次布线WNS为−0.330ns、4个失败端点，最差路径在UART元数据选择。原构建流程继续物理优化，同一RTL与100MHz/IO约束下最终WNS=0.088ns、WHS=0.006ns，建立/保持失败端点均为0，DRC无Error/Critical Warning。以`build_split/timing_refined.rpt`为准。构建日志中的已有IP生成提示和一般Warning仍保留，不声称全日志零警告。
- 最终15,587 LUT、18,829 FF、40 RAMB36+9 RAMB18、9 DSP；相对前缀过滤版增加534 LUT和181 FF，BRAM/DSP不变。资源以`utilization_refined.rpt`为准。
- 最初实机100帧中牌面底部已出画，动态定位返回空结果。这只能验证完整采集和空定位参考一致，不能计为OCR通过。记录保留在`reports/split_board_100`。用户将牌面上移后再测试。
- 上移后预检10/10为BD12345；其中9张需拆分、1张本来分开。见`reports/split_aligned_precheck`。
- 第一轮收到100个完整识别组，全部BD12345；95张需拆分、5张保持原框。但期间有4个内部不完整组、一个会话开头残组及1次CRC候选拒绝，帧号间存在额外间隔。板上bad_captures与publisher_dropped均为0，不能据此断言USB/PC或线上哪一处导致断片；此轮不算无丢失连续验收。见`reports/split_aligned_100`。
- 复测连续100个识别组：帧号5249至5645，间隔均为4；100/100 BD12345，700个字符、537,600个归一化像素、25,200个有符号分数全部匹配。88张旧规则仍合并4/5，新规则拆分后正确；12张旧规则已分开，新规则完整保留7个框。CRC候选拒绝0、板上采集错误0、发布丢弃0。仅会话开始时一个缺AIF1的残组以及停止时下一包尾部未完成，不涉及验收区间的100个完整组。见`reports/split_aligned_repeat_100`。
- 复测源帧开始节拍22.50777fps，识别完成5.62696次/s，完整采集到识别结果平均161.77ms。识别忙时跳过源帧属于设计行为，不是视频丢帧；此处未独立测量LCD光学刷新率。

本轮结果证明当前号码、当前完整入镜位置的粘连问题已得到改善，仍未覆盖任意号码、字体、尺度、运动或倾斜。最新对照图为`../reports/split_aligned_repeat_100/split_boxes_comparison.png`。模型权重和归一化未变；构建哈希与完整记录索引在`reports/split_artifacts.json`。
