# V0.4.1：选择高斯，删除引导
用户比较屏幕实拍后认为效果相近，按简单基础原则保留一次3×3高斯＋Sobel。删除引导滤波和10个独有RTL文件，不保留隐藏分支；RTL、模型、PC和脚本均移除算法选择，SW3取消。
保留已验证的读取修正、完整RAW、原EDGE边界、T128、2MHz和LCD总线时序。VGA间歇/每拍吞吐、帧尾、abort/reset、LCD模式切换及串口两视图均需重新回归。
默认LCD无需大快照，正常运行不依赖PC。新资源、时序及上板结果见reports/lcd/acceptance.json。
尚未实施20fps，也没有自适应阈值。本轮不为增加资源占用保留复杂算法。后续先评估阈值，再单独推进连续FIFO和高速显示。
