# 已接通的NT35510显示接口
lcd_top与constraints/basys3_camera_lcd.xdc是当前完整摄像头到LCD入口。8位MCU8080写专用，RD高；命令/参数16位高字节先发，RGB565像素两字节。原NT35510初始化表、总线4/5/3/2拍时序、窗口写入器不改。
640×480 RAW或630×470 EDGE经有限队列送屏，计算核心无ready反压，队列溢出明确报错并停止；没有用PC重算边缘。初始化及RAW/EDGE几何切换清黑背景，切换期间撤销帧接纳。
默认只保留状态/控制VIO，无大快照；可选Snapshot保存抽样输出及同帧同位置Y，不影响全尺寸送屏。
实物已验证八色条、灰阶、棋盘和四色自检，以及RAW、高斯EDGE动态显示；详细限制和收敛后回归见reports/lcd/acceptance.json。尚未测试高速时序或20fps，严格无显示扫描撕裂也未承诺。
