# V0.3 单次平滑与Sobel规格

状态：核心、串口、受控模型、布局布线及自动曝光／增益开启的50张动态实拍验收已通过，实屏联合集成尚未完成；具体证据与限制见reports/validation.md。基线为最新main/2b7f9d6。项目正常计算由Basys3独立完成，PC只做调试和校验。

## 数据路径

VGA 640×480八位Y → 每帧选择一个前处理 → 同一Sobel → RAW/EDGE选择 → 同源串口及显示接口。

- FILTER=0：一次单尺度自引导滤波，5×5局部统计、系数均值和重建；两轮窗口是一次引导滤波的必要内部步骤，不是重复两次平滑。删除原细节回加及BASE/DENOISE/ENHANCE展示模式。
- FILTER=1：一次3×3加权平滑，核为[1,2,1]纵横外积/16，整数四舍五入。
- 两条前处理不串联。加权路径裁到与引导路径相同的中心区域，再共用Sobel。
- Sobel：Gx、Gy为标准3×3核，M=|Gx|+|Gy|，范围0..2040；M≥T输出255，否则0。T按帧锁存，支持0..2040。
- RAW来自原始Y，同坐标随窗口传递，不是滤波后的灰度。两种输出均为630×470有效区域，坐标x=5..634、y=5..474。完整640×480逻辑画布四边补5个黑像素；800×480屏居中显示。
- 单一100 MHz核心时钟，valid可以有空拍；核心不接受显示反压。参数只在帧首锁存，未完成上一帧不得改变当前帧参数。

## 阈值与效果评估

运行时提供手动Sobel阈值。软件做阈值扫描，分别为两种前处理选择初始参数；不把图像细节软阈值与Sobel梯度阈值混用，不声称已经实现自动／局部自适应阈值。

受控噪声场景的预登记验收：平坦区域噪声标准差≤原始输入的0.8倍；低对比边缘和细线召回率≥0.90（允许1像素定位误差）；平坦区域假边缘率≤1%。指标通过不等同真实摄像头所有场景通过；原始实拍及失败项保留。

## 串口与显示

EVG2：32字节头，包含版本、显示模式、滤波选择、尺寸、帧号、payload长度、epsilon、Sobel阈值、裁边和头CRC。payload为630×470灰度或0/255边缘。20字节尾为payload CRC、完整输入Y CRC、输入数、输出数、错误码；均小端。12 Mbaud、8N1，固定COM10，不接触COM15。

先发送头，再接收源像素；即使加权路径较早产生最后一个有效输出，也必须继续接收输入尾部，输入计数完整后才发送尾部。CRC用于一致性检查，不证明真实相机帧没有拼接。

保留NT35510的8位MCU8080、RGB565、800×480初始化及窗口写接口，和独立屏幕自检入口。主像素接口输出帧号／全局坐标／RAW／EDGE／selected，显示与UART可在此同源取数。LCD接线尚须确认，不能给未知引脚编造XDC；保留接口不等于实屏整链验收。

## 相机采集约定

GYF-198 OV7670_FIFO/AL422B，VGA UYVY，水平窗口158/14。WRST独立接Basys3 JB1(A14)，与VSYNC断开。一次采集：在前置HREF中写复位，等待下一完整帧；达到32行后启动读取，按完整行估算写入信用；帧尾在安全距离满足时追加后续两行提交缓存，写地址不再归零。FIFO容量393216B，VGA YUV422为614400B，依赖受控读写并行，不是静态存整帧YUV。

AL422读复位期间已预取byte0(U0)，释放后从byte1(Y0)开始；已消费字节总614400B含预取字节，输出307200个Y像素。诊断双采样只观察同一字节，暂时保留。读时钟2MHz，后续单独测速率。

VSYNC双触发器同步后，低电平连续64周期才接受，上升沿即时跟随同步信号。正常帧结束仍校验480行；超时、缺行、估算溢出、采样不一致均中止。短脉冲位置和宽度可通过VIO读取。

AEC、AGC、AWB均保持开启；COM8=E7，无后续冻结。50张验收解决此前观察到的拼接和采集中断；不同模式先后采集，强反光下的阈值画质和实屏主链另评估。原验收见reports/hardware/camera_acceptance_50，整理后回归见reports/validation.md。
