# V0.4.1 高斯＋Sobel设计规格
## 硬件与目标
Basys3/XC7A35T，GYF-198 OV7670_FIFO/AL422，TK040F1510/NT35510八位8080。FPGA独立计算，PC用于开发校验；屏幕GRAM仅呈现结果。
本轮固定2MHz读取和100MHz处理，尚未实现20fps。相机AEC/AGC/AWB保持开启，已测读取控制和LCD时序不变。

## 唯一处理链
UYVY VGA640×480取Y灰度 → 一次3×3高斯 → 3×3Sobel → 固定阈值128 → 0/255边缘。
高斯核为[[1,2,1],[2,4,2],[1,2,1]]，加8再右移4位实现四舍五入。Sobel使用abs(Gx)+abs(Gy)，大于等于阈值为255。
引导滤波及独有的统计、系数、除法、重建模块全部删除，不保留算法选择或epsilon参数。高斯和Sobel各有独立3行bank，按valid传递像素和坐标，不因LCD停顿反压核心。
为保持既有显示/串口边界，继续输出x5..634/y5..474的630×470有效EDGE；额外裁边仅为接口兼容，不是另一次滤波。
RAW显示原始Y，不是滤波灰度；LCD RAW旁路完整640×480，UART为与EDGE同坐标的630×470 RAW裁剪图。

## 显示与控制
lcd_top默认连续采集。SW0相机/内部斜纹，SW2 RAW/EDGE，SW15暂停下一帧，SW14错误页；SW3算法选择取消，其余未用开关保持0。
RAW写x80..719/y0..479；EDGE写x85..714/y5..474。模式切换先清背景、再接纳新帧；已寄存start使用锁存模式，避免启动竞态。核心到显示的统一一拍寄存保留。
有限队列溢出、坐标/行数/像素数异常、超时均明确报错，不修补像素、不自动吞坏帧重试。

## 串口调试
EVG2帧布局保持32字节头、payload、20字节尾。算法标识固定1(高斯)，原epsilon字段固定64作为历史兼容保留，完全不参与计算，也没有设置入口。含头CRC、payload CRC及完整输入CRC和计数，12Mbaud、COM10；不访问COM15。
PC自动一轮仅RAW和EDGE两张；只存储和显示，不在实时链路替FPGA做滤波。内部源时才调用参考模型做独立校验。
旧引导滤波数据不再作为活动程序的可选输入模式；历史证据可在Git旧提交中查看。

## 验证与下一步
以reports/lcd/acceptance.json区分软件、RTL、时序和实物证据。保留高斯是用户观感接近后的工程简化选择，不宣称所有场景画质更优。阈值128沿用，没有自动或自适应阈值。
下一步先调边缘效果，再单独设计相机供数/FIFO连续调度/LCD带宽的20fps方案；本轮不实施高速读取。
