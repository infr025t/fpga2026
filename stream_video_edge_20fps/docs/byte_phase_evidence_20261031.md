# 600帧连续双字节证据
配置：原生VGA640×480、相机PLL×6、RCLK16.667MHz/SLOW、单次40ns采样、LCD2/2/2/0不变。新增被动UART仅上传160×120双通道概览；没有反压核心，没有整帧缓存，没有按图像内容换字节。
串口：COM10（FT2232 serial210183BCBF83B）12Mbaud；未打开COM15。先收到60个CRC有效固定色条包，两个通道均逐像素符合参考；该轮1个坏包/1个帧号缺口，不能用于图像判断。主机RX缓存扩至1MiB后实拍连续600包：头CRC0错、负载CRC0错、FPGA诊断丢包0、帧号缺口0，源周期22.5077fps。
视觉证据：第1帧偶数字节为正常灰度，前一奇数字节为浮雕；第99帧恰好相反；第25帧内两组通道在中下部互换。实际输出仍是固定偶数字节，没有软件自动换通道。相邻通道直接取同一已采字节序列，VGA唯一字节模型/真实串口波形模型核对通过。
因此确认：浮雕涉及实际亮度/相邻字节角色变化，问题在写屏前；不是LCD或PC串口单独造成。曝光/增强改变不能解释同帧相邻字节结构互换。
黑白目标的行对比度筛查标出34帧疑似明显互换（20帧≥100行、14帧8..99行）。这不是通用错误率统计，漏掉窄带、小区域及其他错误；不能与静态色条1/2500当作同一指标比较。已人工核对第1/25/99帧。
相位转换边界跨帧位置不固定，多数不靠近3个假设128KiB银行边界；单凭现有图像不能把它归为固定FIFO地址bug。此前“旧FIFO轮次区间”CRC重建成立，但不是所有异常都由同一类型覆盖。
尚未分清：FIFO写入字节数/相位变化、模块端读钟多/少边沿、或其他采集电气异常。RTL理想FIFO模型通过与FPGA内部发沿计数不能证明模块实际收到相同边沿。现有线约20cm，无PCLK/WCK观察、无示波器/逻辑分析仪，不能用软件计数代替外部测量。
