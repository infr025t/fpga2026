# 同帧相邻字节诊断
目的：判别RAW下部浮雕灰块是否由亮度/色度相位变化造成；不重排或自动修补像素。
RCLK仍100MHz/6，SAMPLE_PHASE0（发沿后40ns），相机/曝光参数、LCD时序和核心4文件不变。
camera_fifo_video每个正常输出像素保持原pixel，额外记录前一被采的互补奇偶字节pixel_other。IOB仍每个字节只采一次，没有新增RCLK或第二采样点。prefetch首像素没有有效前一字节，概览只取x=3,7,...，排除此无效位置。RAW快照plane0为实际输出Y候选，plane1为preceding_fifo_byte；EDGE和内部参考仍保存对应RAW原像素。
测试模型以每个字节唯一的已知序列核对pixel和前一相邻字节，完整VGA环绕/暂停模型通过。诊断数据不能反向控制处理或显示。
如果同一错误区域plane0失去明暗细节而plane1恢复真实灰度结构，支持相邻字节角色发生交换；仍需进一步区分写入丢/增字节、读沿异常或模块行为。仅凭看起来像浮雕不能直接认定字节交换。
