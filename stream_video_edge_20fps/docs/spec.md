# 连续VGA高于20fps测试设计
测试区隔离，不改main基线和接线。高斯/Sobel及RAW/EDGE尺寸不变。
候选PLL6/CLKRC1按既有HREF估算18MB/s和22.5fps，以上板量测为准。RCLK100MHz/6=16.667MHz，单次IOB采样，名义访问窗口30ns，收紧外部数据路径预算。
正常连续场仅启动时复位FIFO；累计完整行信用、模32位读写差值及>=129字节保护控制读入，每次显示请求614400字节，不在帧间复位，不保留固定100ms空隙；下一场写入自然提交上一场尾部。
LCD2/2/2拍、零gap背靠背16位字，每像素120ns，和RCLK每2字节120ns匹配。最终字完成必须区分同时到达的上一字完成。
硬件锁存完成CRC/像素数/帧周期，独立统计传感器、读取和写屏帧数。可选快照；用户暂停时先排空已接纳帧再停写，恢复重新预备。
模型要覆盖不同帧唯一内容、FIFO跨环绕、行信用/提交延迟、暂停恢复。硬件先固定色条全RAW CRC，再内部EDGE参考和实拍计数/快照；不能以像素数正确替代正确图像。实际玻璃画质因用户不在场待补。

诊断快照：中央同帧原尺度96×96像素，配对存RAW和当前输出，共18432B，不含整帧缓存；32字块通过JTAG导出。VIO固定in0状态、in1相机统计、in2完成帧计数/CRC、in3性能、in4/5数据块、in6快照状态。此快照不参与处理/写屏流控。
启动协议：已发出的camera_admitted必须被相机和显示双方接纳，新到暂停/内部源选择在该拍不取消已承诺的源帧；完成后再暂停。

高速Y字节相位：真实摄像头固定色条的原尺度640×16诊断表明，偶数字节重建全帧CRC=6df0b9b5（与低速正确Y参考相等），奇数字节为UV、CRC=17e5bee9。连续源按实测Y_BYTE=0解码，RRST期间已经预取的第0字节也必须通过同一IOB采样并输出，不能跳过首Y。每帧仍完整消费614400字节，不移动坐标、不复制像素、不按图像内容补带。临时companion_byte探针已删除，RAW快照恢复同帧原始Y。SCCB所声明的UYVY与FIFO实际起始相位要区分，不把相位错误归咎算法或屏幕。

当前诊断构建为全宽16行strip：RAW640×16、EDGE630×16，源物理y=232..247；配对RAW/当前输出。这样可核对色条每列并形成准确的完整参考。此前96×96为过渡诊断版本，最终测试报告按bit哈希对应具体布局。全帧bars_monitor另行比较每个固定色条像素，只记录错误数量和首尾位置，不替换数据。屏幕实际显示仍为完整640×480/630×470。
