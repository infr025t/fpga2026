# 2500帧统计口径
用户要求额外测试2500张并统计错误。保持现有20cm接线、PLL×6、RCLK16.667MHz/SLOW、LCD2/2/2/0、真实相机固定色条RAW640×480。
诊断构建参数STAT_FRAMES=2500：CRC异常继续处理，不触发ref_fault停止；每一完成帧在FPGA内比较完整307200字节CRC与6df0b9b5，累计reference_failures。恰好完成2500帧后阻止新帧并排空停写。普通构建STAT_FRAMES=0保留原本遇错停止方式。
不改滤波/Sobel或摄像头字节解码，源/显示溢出等错误仍停止并报告未完成，不能把它们记为正常图像。
host轮询仅输出明细和观测到的错误位置，不作为总错误数依据；计数由FPGA完成，轮询漏帧也不漏计。测试结果将注明host漏记数量。测试仍是固定图像数据完整性，不能替代真实动态光照或屏幕实际观感。
新增统计模式会改变诊断逻辑及布局，不能把与旧1500帧结果的差别简单视为线缆性质改变。数值核心保持原文件hash。
