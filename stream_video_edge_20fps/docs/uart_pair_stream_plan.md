# 连续相邻字节诊断（测试专用）
目标：记录同一源帧的160x120双通道小图，捕获动态浮雕/相位变化，不以静态色条代替动态验证。
接口：现有uart_fast_tx 12Mbaud/100MHz，Basys3 TX A18，PC COM10；禁止打开COM15。
每帧38400B +32B头+4B CRC，22.51fps约865KB/s，低于UART实际约1.18MB/s。每4行的一行抽样，单行320B，峰值积压约230B，使用1024B字节FIFO，不返压核心。源最后3行无诊断像素，尾部充分排空。
头：8字节magic YVPAIR1!，u32帧号、u16宽160、u16高120、u32负载38400、u32时刻、u32诊断丢帧计数、u32头CRC；payload逐像素even/preceding-odd交错，尾4B payloadCRC。所有整数小端。
出现FIFO/包组装溢出只丢诊断包并累计计数，不能暂停相机或更改核心像素。PC按magic/头CRC/负载CRC同步并记录每帧；包错误与摄像头图像异常分开统计。
实现顺序：发送波形/CRC仿真 -> 仅诊断链集成与时序 -> COM10校验确定性条纹 -> 连续实拍记录300帧并检查配对图。保持40ns单采样/16.667MHz读钟、相机参数不变。

CRC错误可能来自串口链路，也可能来自FPGA诊断FIFO丢包后的截断包，须结合dropped/帧号缺口判别。包正确只证明所回传样本在链路上传输一致，不证明原始摄像头内容正确。
