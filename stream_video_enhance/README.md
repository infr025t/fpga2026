设计方向：固定 5×5 单尺度自引导滤波、两轮局部统计、软阈值细节增强；100 MHz 单核心时钟，帧内 II=1；两轮独立行缓存携带中心原像素，减少复杂的存储复用和对齐控制。每边裁掉 4 像素。显示/串口只读取独立的小预览快照，忙时跳过整帧预览，不能阻塞主处理链。

本次修订撤销未经画质验证的增强默认值：先用同输入RAW/BASE/DENOISE/ENHANCE对照选定发布参数，再进入算法RTL。固定延迟由L_CORE统一推导，不要求凑成64拍。19,200 B快照增加同帧同坐标96×96 RAW/处理双ROI布局，采用16位成对写入，保持5个快照BRAM36；完整核心RAW/处理CRC通过图像包或独立STATUS可读取。新增诊断会增加少量逻辑与寄存器，未宣称资源成本为零。

预期效果是形成真正可连续工作的计算核心，并具备保边平滑和受控增强能力；实际画质、资源、时序和摄像头帧率尚未验证。现有 OV7670_FIFO 用于过渡联调，不据此宣称连续高速摄像头输入已经实现。屏幕先维护逻辑接口，采购和物理驱动留到后续阶段。

规格包含算法与定点规则、像素接口、逐级延迟、RAM端口、资源预算、错误恢复、外设边界及验收条件。模型数值验收已通过。用户授权的全部已定义ε及G512扩大搜索已执行，公式、位宽与相对RAW的+5%门槛保持不变。第一、二轮均保留FAIL；进一步调整须按第17节基于实测权衡讨论。VGA在这里表示分辨率，屏幕接口仍独立待定。
