# 项目简介

本项目基于Basys 3开发板（Artix-7 XC7A35T FPGA），搭配GYF-198 OV7670_FIFO摄像头模块与8位并口NT35510液晶屏，构建独立运行的灰度视频增强系统。系统采集640×480图像的亮度信息，由FPGA完成保边降噪与受控细节增强，并完整显示裁边后的632×472灰度画面。处理核心采用单尺度引导滤波，通过局部统计保留边缘、平滑噪声，再对细节进行阈值抑噪、增益调节和限幅。硬件采用定点流水线与两轮独立行缓存，按每拍一个有效像素组织计算，减少对整帧存储的依赖，在有限片上资源下兼顾连续处理与实现复杂度。系统设计提供未增强灰度、滤波、降噪和增强模式对照，便于展示处理效果；正常运行无需电脑参与计算。
