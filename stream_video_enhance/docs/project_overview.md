# 项目简介

本项目基于Basys 3开发板（Artix-7 XC7A35T FPGA），使用现有GYF-198 OV7670_FIFO摄像头，目标搭配TK040F1510（NT35510、8位MCU8080）屏幕，构建独立运行的灰度视频增强系统。目标是采集640×480亮度图，由FPGA完成保边降噪和受控细节增强，在800×480横屏中央完整显示裁边后的632×472灰度画面。处理核心采用单尺度引导滤波、定点流水线与两轮独立行缓存，按每拍一个有效像素组织计算，减少对整帧存储的依赖。系统设计提供RAW、BASE、DENOISE、ENHANCE模式对照，正常计算无需电脑。

当前数值核心和有界运行时已有仿真证据；屏幕驱动及独立自检已编写。现有相机的VGA并发采集、主链显示集成、实物接线、全系统时序及Flash冷启动尚未完成，不能将上述目标当成整机已验收结果。最新范围见[实施状态](status.md)和[屏幕适配说明](hardware/TK040F1510.md)。
